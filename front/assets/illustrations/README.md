Não redistribuir o pacote completo como biblioteca de recursos.

> **Atenção para publicações externas e científicas:** como o pacote gratuito original não traz licença formal identificável, verifique os direitos de uso ou evite reproduzir estas ilustrações diretamente em figuras de artigos ou materiais externos.
