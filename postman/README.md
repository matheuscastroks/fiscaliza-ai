# Validação da API

Importe `fiscaliza.collection.json` e configure `baseUrl` para a API local. A coleção cobre autenticação, perfil e consultas públicas do 1746/Data.Rio. Não cria ocorrências, propostas, consultas ou ações públicas.

Não há contas pré-criadas. Cadastre uma conta e configure email/password na coleção para os fluxos de login e perfil. Contas, tokens e senhas de validação devem ser configurados localmente, sem incluir credenciais reais no repositório. Fixtures de cadastro são exclusivas dos testes.
